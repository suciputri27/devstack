name: research-lite
description: Small technical research such as comparing libraries, checking a framework API change, or finding a fix for an error.
---
1. Restate the question in one line.
2. Use Context7 for library docs first, then web search. At most 6 sources, prefer official docs and changelogs.
3. Note the version each source applies to.
4. Output: answer first, then a short comparison table if relevant, then sources with links.
5. Save to docs/research/YYYY-MM-DD-topic.md only if asked.
