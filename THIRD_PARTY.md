# Komponen pihak ketiga

Kecuali font yang disebut di bawah, devstack tidak menyertakan kode komponen di bawah ini. Installer mengunduh masing-masing dari sumber resminya saat dijalankan. Setiap komponen tetap tunduk pada lisensinya sendiri.

| Komponen | Sumber | Lisensi |
| --- | --- | --- |
| oh-my-pi (OMP) | github.com/can1357/oh-my-pi | MIT |
| 9Router | github.com/decolua/9router | MIT |
| SearXNG | github.com/searxng/searxng | AGPL-3.0 (dijalankan sebagai layanan terpisah, tidak dimodifikasi) |
| BMAD Method | github.com/bmad-code-org/BMAD-METHOD | MIT. "BMAD" dan "BMAD-METHOD" adalah merek dagang BMad Code, LLC |
| Impeccable | github.com/pbakaus/impeccable | Apache-2.0 |
| UI UX Pro Max | github.com/nextlevelbuilder/ui-ux-pro-max-skill | MIT |
| Orca | github.com/stablyai/orca | Lihat repositori resminya |
| Playwright MCP | github.com/microsoft/playwright-mcp | Apache-2.0 |
| Playwright (Python) | github.com/microsoft/playwright-python | Apache-2.0 |
| Semgrep CE | github.com/semgrep/semgrep | LGPL-2.1 (dipasang dari PyPI, tidak dimodifikasi) |

Font yang disertakan di `brain/taste-pack/fonts/` (Bricolage Grotesque, Geist, Geist Mono, Instrument Serif, Public Sans, IBM Plex Mono, Plus Jakarta Sans, Fraunces) berlisensi SIL Open Font License 1.1, salinan lisensinya ada di `brain/taste-pack/fonts/licenses/`.

Nama produk di atas dipakai hanya untuk menyebut komponen yang dipasang. devstack tidak berafiliasi dengan, atau didukung oleh, pemilik komponen tersebut.
